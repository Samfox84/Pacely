# Sounds inside Pacely

Put `.mp3` (or `.m4a`) files here with these names. Missing ones fall back to a soft chime or silence.
Switch sounds on or off in **Me › Sounds**.

| File name | When it plays |
|---|---|
| `done.mp3` | You tick something off |
| `step.mp3` | You tick off a step |
| `add.mp3` | You add something |
| `next-step.mp3` | The focus timer moves to the next step |
| `timer.mp3` | Focus time is up |

On a Pacely server, they go in `/opt/pacely/static/sounds/`. Keep them short and soft.
